# Architektur-Entscheidungen

Begründungen, die früher als Kommentare im Code standen, stehen hier, eine Datei je Entscheidung
(Regel: [ADR 0001](0001-keine-code-kommentare.md)). Format: Titel, ein bis drei Sätze Kontext,
Entscheidung und Grund, danach Messwerte und verworfene Alternativen, am Ende `Betrifft:` mit den
Symbolen im Code. Neue ADRs bekommen die nächste freie Nummer.
